# Вікі «Пустельників»: джерело

Тут лежать правила гри — джерело правди над усіма іншими текстами (виправлена редакція, epub, дані HTML-інструментів, компендіуми Foundry). До 2026-11-28 вікі жила в Notion (https://sergeyten.notion.site/21de66cd8c78803186b2e9a38f160a4f); її перенесено сюди скриптом `site/convert_notion.py`, відтоді правки — лише тут.

## Що де
| Файл | Що |
|---|---|
| `contents.yml` | **Порядок, одне місце:** групи («ПРАВИЛА ГРАВЦІВ», «ПРАВИЛА ДОГЛЯДАЧА (ВЕДУЧОГО)») → розділи → сторінки. Переставити сторінку = переставити рядок тут. Також головна (`home`) і картинки-кнопки головної (`buttons`: `text` — назва картинки в Notion, `label` — напис кнопки на сайті, якщо інший, `link` — куди веде, `menu: false` — кнопки немає в меню сайту). |
| `pages/<slug>.md` | Одна сторінка. Ім'я файлу латиницею (транслітерація за постановою КМУ № 55, 2010): `robymo-perevirky.md`. |
| `images/` | Картинки сторінок (обкладинка, кнопки головної, знак ліцензії). |
| `home/de-hraty.md` | Вступ «Де грати» на головній (тексти колишньої `index.html`, пакет Б, 2026-11-28). Не сторінка вікі: його читає лише збірка сайту, формат нижче. |
| `files/` + `downloads.yml` | Файли для скачування (мапа, фішки, пам'ятки, аркуші, PDF швидкого старту), пакет Г-Б, 2026-11-28; формат нижче. |
| `notion-anchors.yml` | 35 посилань, які в Notion вели на місце всередині сторінки (експорт лишив тільки сторінку). Сайт поверне їх на етапі 3. |

## Сторінка
```markdown
---
title: "Робимо перевірки"
notion: "21de66cd8c7880fd9409cc209bf87e80"
tool: all_generators.html#battle
---

Текст сторінки в Markdown…
```
- `title` — назва сторінки; так її знаходять скрипти (`tools/wiki_sync`) і тести DEV-системи Foundry. Назва має бути одна на всю вікі.
- `notion` — id сторінки в Notion: за ним звіряють старі посилання й архів, і компендіуми Foundry тримають ним свої id. Не міняти.
- `tool` (не на всіх) — інструмент сайту, до якого веде сторінка (`all_generators.html#…`, `character_generator.html`, `caravan_generator.html`).
- `site: false` (не на всіх) — сторінки немає на сайті: ні в меню, ні на головній, ні окремою адресою. Компендіуми Foundry й далі її отримують (`contents.yml` її лишає). Посилання на таку сторінку зупиняє збірку, якщо немає `site_at`.
- `site_at: <slug>` (разом із `site: false` і `tool`) — сторінка, де стоїть кнопка цього інструмента: одразу після виноски, яка посилається на цю сторінку (без такої виноски збірка зупиняється). Посилання з інших сторінок ведуть на кнопку (`<slug>/#<ця сторінка>`), а з самої `<slug>` — одразу в інструмент. Так «Автоматичні генератори битв / подорожей / справ» стоять кнопками на «Складність битв», «Подорожі та випадкові події», «Структура сесії, створення справ» (пакет Г-А, автор 2026-11-28).

- `compendium: false` (пакет Г-Б, 2026-11-28) — сторінка лише для сайту: «Пам'ятка гравця», «Пам'ятка Доглядача» і 21 сторінка «Швидкого старту» (група «ШВИДКИЙ СТАРТ» у `contents.yml`). Компендіуми Foundry її не бачать (`to_notion_layout` її пропускає, розділ без жодної сторінки компендіуму — теж). Без `notion`; сторінка компендіуму не може на неї посилатися (збірка зупиняється). Ці сторінки перенесено з Foundry скриптом `site/import_foundry.mjs` (поля `source` і `import_sha`): відтоді правляться тут; `import_sha` збігається з текстом, доки його не правили, і тоді тест звіряє сторінку з Foundry дослівно.

## Файли для скачування (`files/`, `downloads.yml`)
- Файл лежить у `files/` (ім'я латиницею) і описаний у `downloads.yml`: `file`, `name` (ім'я, під яким браузер його збереже), `label` (напис кнопки, завжди «Скачати …»), `drive` (id файлу на Google Drive автора, якщо він там був). Файл поза `downloads.yml` чи запис без файлу зупиняє збірку.
- **Посилання на Google Drive** у старих сторінках лишаються як були (їх читають компендіуми). Сайт робить із них кнопки: абзац чи заголовок, що є лише посиланням (або голою адресою), стає кнопкою; посилання посеред речення лишає свої слова текстом, а кнопка стає в кінці абзацу чи пункту списку. В «Історії змін» на головній кнопок немає, лише слова. Посилання на файл Drive, якого немає в `downloads.yml`, зупиняє збірку.
- На сторінках лише для сайту кнопка — це абзац з одного посилання на файл: `[Скачати PDF](../files/shvydkyi-start.pdf)`; напис кнопки — слова посилання.
- Посилання на файл у самому кінці абзацу чи пункту списку стає кнопкою в кінці цього абзацу чи пункту (готові персонажі на «Ким можна грати», 2026-11-28): `… не протягне й року. [Скачати Волті](../files/hotovyi-personazh-volti.pdf)`. Посилання на файл посеред речення зупиняє збірку.

## Текст
- Звичайний Markdown з таблицями.
- **Посилання на іншу сторінку:** `[Наслідки](naslidky.md)`. **На розділ:** `[Аспекти](../contents.yml#aspekty)`. На сайт інструментів — повною адресою `https://serhiiten.github.io/wastelanders/…` (скрипт приміток Foundry шукає саме її).
- **Картинка:** `![підпис](../images/cover.png)`.
- **Виноска** (у Notion — callout) — блок GitHub, перший рядок — значок:
  ```markdown
  > [!TIP]
  > ☝
  >
  > **Викликати аспекти можна** …
  ```
  `[!TIP]` для ☝, `[!WARNING]` для ⚠️, `[!NOTE]` для решти. Власні значки Notion лежать як невидимий коментар `<!-- notion-emoji: … -->`: не видаляти, доки сайт не має своїх.
- Аспекти в рядку «Аспекти:» компендіуми розділяють «; », вікі — комами; так і лишається (`tools/wiki_sync` тримає «; » сам).

## Вступ на головній (`home/de-hraty.md`)
Сайт ставить його між обкладинкою з меню і блоками правил: три таблички-екрани в ряд, «Докладніше» відкриває під ними панель.
```markdown
# Де грати
Вступний абзац.

## Owlbear Rodeo {#owlbear}
`Безкоштовно` `Легко`

Перший абзац — текст таблички.

Решта — панель «Докладніше»: списки, `#### Підзаголовок`, `### Як встановити` (згортка всередині панелі).
Адреса, яку треба копіювати, — окремим рядком у `лапках`: `https://…` (стає полем з кнопкою «Копіювати»).
```
- Рівно чотири розділи `## Назва {#id}`: три таблички й завершальний блок (зараз «Одна Пустка на всіх»). `#owlbear` і `#foundry` обов'язкові: на них ведуть кнопки меню (`contents.yml`, `link: "#owlbear"`) і старі адреси `index.html#owlbear`. Без них збірка зупиняється й називає файл.
- Рядок цінників під заголовком: перший — ціна (зелений, якщо «Безкоштовно»), решта — позначки.
- Список інструментів після рядка `<!-- інструменти -->`: `- [Назва](https://serhiiten.github.io/wastelanders/….html): опис` — картки, які відкривають інструмент у рамці вікі.

## Хто читає
- **Сайт** — `site/build.py` (через `site/wikisrc.py`): `python site/build.py` збирає `_site/rules/` (сторінки, пошук Pagefind) і `_site/404.html`; `python site/serve.py` показує їх на http://localhost:8800/wastelanders/rules/ так, як віддасть GitHub Pages. Якір на заголовок іншої сторінки: `[текст](storinka.md#id-zaholovka)`, id — назва заголовка латиницею (як ім'я файлу).
- **Компендіуми Foundry** (`tools/wiki_sync` робочої теки, `--wiki <цей репозиторій>`): `wikisrc.Wiki.to_notion_layout()` розкладає джерело в тимчасову теку так, як лежав експорт Notion, і скрипти синхронізації працюють як раніше. Читають лише `main`, що дорівнює `origin/main`.
- **Тести DEV-системи** (`tests/wiki-source.mjs`): сторінка за назвою.

## Перевірка
```
python site/tests/test_convert.py
python site/tests/test_build.py
```
Битне посилання, сторінка поза `contents.yml`, невідомий розділ чи картинка, залишки адрес Notion — тест падає й називає файл. Збірка сайту на такому джерелі теж зупиняється й називає файл.
