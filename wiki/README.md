# Вікі «Пустельників»: джерело

Тут лежать правила гри — джерело правди над усіма іншими текстами (виправлена редакція, epub, дані HTML-інструментів, компендіуми Foundry). До 2026-11-28 вікі жила в Notion (https://sergeyten.notion.site/21de66cd8c78803186b2e9a38f160a4f); її перенесено сюди скриптом `site/convert_notion.py`, відтоді правки — лише тут.

## Що де
| Файл | Що |
|---|---|
| `contents.yml` | **Порядок, одне місце:** групи («ПРАВИЛА ГРАВЦІВ», «ПРАВИЛА ДОГЛЯДАЧА (ВЕДУЧОГО)») → розділи → сторінки. Переставити сторінку = переставити рядок тут. Також головна (`home`) і картинки-кнопки головної (`buttons`: `text` — назва картинки в Notion, `label` — напис кнопки на сайті, якщо інший, `link` — куди веде, `menu: false` — кнопки немає в меню сайту). |
| `pages/<slug>.md` | Одна сторінка. Ім'я файлу латиницею (транслітерація за постановою КМУ № 55, 2010): `robymo-perevirky.md`. |
| `images/` | Картинки сторінок (обкладинка, кнопки головної, знак ліцензії). |
| `notion-anchors.yml` | 35 посилань, які в Notion вели на місце всередині сторінки (експорт лишив тільки сторінку). Сайт поверне їх на етапі 3. |

## Сторінка
```markdown
---
title: "Робимо перевірки"
notion: "21de66cd8c7880fd9409cc209bf87e80"
tool: all_generators.html#battle
---

Текст сторінки в Markdown…
```
- `title` — назва сторінки; так її знаходять скрипти (`tools/wiki_sync`) і тести DEV-системи Foundry. Назва має бути одна на всю вікі.
- `notion` — id сторінки в Notion: за ним звіряють старі посилання й архів, і компендіуми Foundry тримають ним свої id. Не міняти.
- `tool` (не на всіх) — інструмент сайту, до якого веде сторінка (`all_generators.html#…`, `character_generator.html`, `caravan_generator.html`).

## Текст
- Звичайний Markdown з таблицями.
- **Посилання на іншу сторінку:** `[Наслідки](naslidky.md)`. **На розділ:** `[Аспекти](../contents.yml#aspekty)`. На сайт інструментів — повною адресою `https://serhiiten.github.io/wastelanders/…` (скрипт приміток Foundry шукає саме її).
- **Картинка:** `![підпис](../images/cover.png)`.
- **Виноска** (у Notion — callout) — блок GitHub, перший рядок — значок:
  ```markdown
  > [!TIP]
  > ☝
  >
  > **Викликати аспекти можна** …
  ```
  `[!TIP]` для ☝, `[!WARNING]` для ⚠️, `[!NOTE]` для решти. Власні значки Notion лежать як невидимий коментар `<!-- notion-emoji: … -->`: не видаляти, доки сайт не має своїх.
- Аспекти в рядку «Аспекти:» компендіуми розділяють «; », вікі — комами; так і лишається (`tools/wiki_sync` тримає «; » сам).

## Хто читає
- **Сайт** — `site/build.py` (через `site/wikisrc.py`): `python site/build.py` збирає `_site/rules/` (сторінки, пошук Pagefind) і `_site/404.html`; `python site/serve.py` показує їх на http://localhost:8800/wastelanders/rules/ так, як віддасть GitHub Pages. Якір на заголовок іншої сторінки: `[текст](storinka.md#id-zaholovka)`, id — назва заголовка латиницею (як ім'я файлу).
- **Компендіуми Foundry** (`tools/wiki_sync` робочої теки, `--wiki <цей репозиторій>`): `wikisrc.Wiki.to_notion_layout()` розкладає джерело в тимчасову теку так, як лежав експорт Notion, і скрипти синхронізації працюють як раніше. Читають лише `main`, що дорівнює `origin/main`.
- **Тести DEV-системи** (`tests/wiki-source.mjs`): сторінка за назвою.

## Перевірка
```
python site/tests/test_convert.py
python site/tests/test_build.py
```
Битне посилання, сторінка поза `contents.yml`, невідомий розділ чи картинка, залишки адрес Notion — тест падає й називає файл. Збірка сайту на такому джерелі теж зупиняється й називає файл.
